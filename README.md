# Proyecto Playwright

Este proyecto contiene una configuración básica para automatización de pruebas con Playwright en JavaScript.

## Comandos principales

- `npm test`: Ejecuta las pruebas (configuración personalizada recomendada).
- `npx playwright test`: Ejecuta las pruebas con Playwright.

## Primeros pasos

1. Instala dependencias: `npm install`
2. Ejecuta una prueba de ejemplo: `npx playwright test`

## Documentación

Consulta la documentación oficial de Playwright: https://playwright.dev/
